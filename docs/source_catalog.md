# Catálogo de fuentes

El catálogo operativo se encuentra en `config/sources.json`.

Principios:

- fuentes oficiales como autoridad primaria;
- fuente última/original declarada;
- política de frescura por fuente;
- fallo de descarga no borra el último snapshot bueno;
- granularidad geográfica declarada;
- caveats conservados en metadata.

La dimensión migratoria de v0.1 **no utiliza SERMIG**.
